# Claude + Codex as Co-Founders — Rocket Fuel Framework

**Source:** [Instagram Reel](https://www.instagram.com/reel/Dajsl8WxKlQ/)
**Added:** 2026-09-13
**Tags:** claude, codex, agents, workflow, ai-tooling

## The Concept
Use Gina Wickman's *Rocket Fuel* (Visionary + Integrator framework) as the mental model for
structuring Claude and Codex as complementary AI co-founders with explicit role clarity.

- **Claude = Visionary** — big picture thinking, architecture decisions, planning, review
- **Codex = Integrator** — execution, grinding through implementation, shipping

## The Setup
1. Get a summary of *Rocket Fuel* (YouTube or PDF) as context
2. Install the Codex skill for Claude Code (GitHub repo: comment "Rocket" on the reel to get link)
3. Combine into a system prompt that gives each model its explicit role

## Why the Framing Matters
The Rocket Fuel book specifically covers how Visionary/Integrator pairs avoid stepping on each
other and duplicating work. That maps directly to preventing Claude and Codex from going in
circles or contradicting each other on a task.

## Jose's Status
Already running this exact stack (Claude Max + Codex Max). Adding explicit role framing to
system prompts could tighten the handoff and reduce back-and-forth.

## Verdict
Solid mental model, not a new workflow. The value is in the system prompt framing — worth
adding explicit Visionary/Integrator role language to Claude Code sessions.
